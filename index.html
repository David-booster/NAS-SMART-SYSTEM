NAS SMART SYSTEM

A private, single-user tool for syncing my own Google Drive files to my home NAS.

What it does

NAS SMART SYSTEM is a personal configuration of the open-source tool rclone, running on a privately owned home NAS. It uses the Google Drive API to copy and synchronize files between the owner's Google Drive and the NAS, so that scheduled jobs on the NAS can read and write working files.

Who it is for

This application is used only by its owner. It is not offered to the public, has no sign-up, and no other users' data is accessed.
