Privacy Policy

NAS SMART SYSTEM · Effective date: November 27, 2026

NAS SMART SYSTEM ("the app") is a private, single-user application. It is a personal configuration of the open-source tool rclone, running on a home NAS owned and operated by the app's developer. The developer is also the app's only user.

1. Data the app accesses

With the owner's explicit authorization through Google OAuth, the app accesses files and folders in the owner's own Google Drive in order to copy and synchronize them with the owner's NAS. The app does not access contacts, email, calendar, location, or any other Google account data.

2. How the data is used

Google Drive data is used only to provide the sync function described above. It is not used for advertising, profiling, analytics, or training of any model.

3. Storage

Synchronized files and the OAuth token are stored only on the owner's private NAS. There is no external server, database, or cloud service operated by the app.

4. Sharing

The app does not sell, rent, transfer, or disclose Google user data to any third party.

5. Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the rclone configuration on the NAS removes the stored token; synced copies can be deleted from the NAS by the owner at any time.

7. Changes

Any changes to this policy will be posted on this page with a new effective date.
